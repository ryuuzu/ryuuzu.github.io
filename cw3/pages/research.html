Research

This is the research section of the page. It contains screenshots from various other sites that inspired this portfolio to be designed in this way. The concepts were taken from these sites while the coding was figured out with some research and experimentation.
Note: You might see a few changes in the HTML texts that were applied after this research page. You can also click on the images to go to the site.

Age Counter

To implement this on the website, a function was defined that constantly updates the age container at the speed of 10 milliseconds. This was one of the easiest solutions with the help of some JavaScript.

Contact Form

This implementation was the easiest one compared to other ones here. The form elements were easily aligned with the help of <table>...</table> tags.

Dropdown

This was implemented by defining a JavaScript function to add a class that has the dropdown properties to the dropdown content.

Sidebar

This was implemented with the help of CSS and a little touch of JavaScript. Everything here was mostly CSS and JavaScript was used to change the width of the sidebar.

Sticky Navigation Bar

To implement this on the website, the top navigation bar was styled with a few CSS styles. This was also pretty easy to implement as it required only few CSS were required.
